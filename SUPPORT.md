# Support

- Use GitHub Discussions for usage questions and design conversations.
- Use the bug report form for reproducible defects.
- Use the performance report form for streaming, memory, or rendering regressions.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Before asking for help, run `CopcPointCloud.validateUrl(url)` and confirm that the
server supports CORS and HTTP `206 Partial Content`. Include diagnostics with private
URLs, tokens, and dataset details removed.
